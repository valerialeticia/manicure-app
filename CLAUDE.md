# Manicure App

Next.js (App Router) + React + TypeScript, PWA. Arquitetura MVP (Model / View / Presenter) descrita no [README.md](README.md).

## Regras de nomenclatura

- Nomes de funções, variáveis, constantes, parâmetros, tipos, interfaces, componentes, hooks, arquivos e pastas são **sempre em inglês**, inclusive em testes.
- Em português ficam apenas textos exibidos na interface, mensagens de erro mostradas à usuária, descrições de testes (`describe`/`it`) e comentários.
- `camelCase` para funções/variáveis, `PascalCase` para tipos/componentes, `UPPER_SNAKE_CASE` para constantes globais, hooks com prefixo `use`.

## Comandos

- `npm test` — testes unitários
- `npm run typecheck` — checagem de tipos
